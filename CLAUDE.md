# claude-plugin-sdlc

## Checks

- `make test` and `make lint` must pass before work is done; `make fmt` fixes formatting.
- `make evals MODEL=sonnet SCENARIOS="a b"` runs the plugin evals. The default model is Opus,
  and a full Opus run costs about $11, so name the scenarios that matter.

## Conventions

- The ticket and intent hashes in `tools/specs/sdlc_specs/snapshot.py` are frozen: they are
  committed in product repos. A new algorithm gets a versioned prefix (`sha256v2:`) and the old
  one stays accepted; never edit one in place.
- Lint rule fixtures are generated by `tools/specs/tests/make_lint_fixtures.py`; every rule needs
  a `-pass` and a `-fail` fixture.
- Editing a file in `tools/specs/sdlc_specs/templates/` needs its new hash added to
  `templates/HISTORY`, so `/sdlc:init --upgrade` still recognises unedited copies.

## Releases

- Bump the version in `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`,
  `tools/specs/VERSION` and the `CHANGELOG.md` heading.
- Each release section in the changelog lists every command; a test fails otherwise.
- Tag as `sdlc--vX.Y.Z`, annotated.
